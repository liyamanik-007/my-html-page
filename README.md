# My First HTML Project - Favorite Things

A simple, responsive single-page website built to practice and showcase essential HTML elements, custom fonts, and styling.

## 🚀 Features & Elements Included
* **Typography:** Custom Google Fonts (**Parkinsans** for headings, **Bitcount Grid Single** for body text).
* **Lists:** Organized collections using unordered (`<ul>`) and ordered (`<ol>`) tags.
* **Media:** Embedded kitten image (`<img>`) and an interactive video player (`<video>`).
* **Data Table:** A clean schedule layout using `<table>`, `<th>`, `<tr>`, and `<td>` tags.
* **Hyperlinks:** External link linking out to the W3Schools HTML Tutorial.

## 📂 File Structure
* `index.html` - Contains all the HTML markup and internal CSS styling.

## 💻 How to Run Locally
1. Open the project folder in **VS Code**.
2. Click **Go Live** in the bottom right corner (via the Live Server extension) to view it in your browser.
